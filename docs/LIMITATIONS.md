# Known limitations
- No email, SMS, or push provider is integrated; no remote notification is sent.
- No verified help-point dataset or offline map tiles are included.
- Self-service account deletion is not exposed in this starter.
- Journey check-ins are manual; no reliable background timer or automatic escalation.
- Local IndexedDB is not encrypted and can be cleared by browser storage management.
- Service-worker offline behavior and geolocation must be verified in target browsers/devices.
- Production deployment hardening and accessibility testing remain necessary. This is not a substitute for emergency services.
